# Spark

Красивый трекер привычек прямо в терминале.

Зажигай серии. Не давай им погаснуть.

## Возможности

- Добавление и удаление привычек
- Отметка выполнения за сегодня
- Подсчёт текущей и лучшей серии (streak)
- Красивая статистика
- Данные хранятся локально в `~/.spark/`
- Минималистичный и приятный интерфейс

## Установка

```bash
git clone https://github.com/fima4335/spark.git
cd spark
pip install -r requirements.txt
```

## Использование

```bash
python spark.py
```

### Команды внутри приложения

| Команда | Действие |
|--------|----------|
| `a` / `add` | Добавить новую привычку |
| `d` / `done` | Отметить привычку выполненной сегодня |
| `r` / `remove` | Удалить привычку |
| `s` / `stats` | Показать подробную статистику |
| `q` / `quit` | Выход |

---

Маленькие шаги каждый день создают большие изменения.
